# «Не Парься» — сайт-витрина услуг для студентов

Одностраничный сайт без бэкенда. Клиент собирает заказ в конструкторе, и заявка уходит вам в Telegram: текст подставляется в чат и одновременно копируется в буфер обмена.

## Что в папке

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы и все тексты блоков |
| `styles.css` | Оформление, дневная и ночная темы |
| `script.js` | Конструктор, сводка, отправка в Telegram, карусель, FAQ |
| `sounds.js` | Мягкие звуки кликов (Web Audio, без аудиофайлов) |
| `config.js` | **Ваши настройки**: Telegram, подключение базы, подписи счётчиков, примеры работ, FAQ |
| `supabase-setup.sql` | Скрипт, который один раз создаёт базу для счётчиков и отзывов |
| `assets/` | Иконки сайта и картинка-превью для мессенджеров |

Чтобы посмотреть сайт у себя, дважды кликните по `index.html`, он откроется в браузере. Всё работает и так, но копирование в буфер надёжнее на настоящем адресе с https, то есть после публикации.

## Как опубликовать сайт и получить ссылку

### Способ 1. Netlify — самый простой (2 минуты)

1. Откройте **https://app.netlify.com/drop**.
2. Зарегистрируйтесь: подойдёт вход через Google или почту. Это бесплатно.
3. Перетащите **всю папку `ne-parsya`** мышкой в область на странице (туда, где написано «Drag and drop your site output folder here»).
4. Через несколько секунд появится ссылка вида `https://случайное-имя.netlify.app`. Сайт уже работает.
5. Чтобы сделать имя красивее: **Site configuration → Change site name**, например `ne-parsya`. Получится `https://ne-parsya.netlify.app`.

**Как обновить сайт после правок:** откройте сайт в Netlify, зайдите во вкладку **Deploys** и снова перетащите папку в поле внизу страницы («Drag and drop…»). Ссылка останется прежней.

### Способ 2. GitHub Pages

1. Зарегистрируйтесь на **https://github.com**.
2. Нажмите **+** справа вверху → **New repository**.
   - Repository name: например `ne-parsya`.
   - Выберите **Public**.
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите **содержимое** папки (файлы `index.html`, `styles.css`, `script.js`, `sounds.js`, `config.js`, `README.md` и папку `assets`). Важно: `index.html` должен лежать в корне репозитория, а не внутри ещё одной папки.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages** (меню слева).
   - Source: **Deploy from a branch**.
   - Branch: **main**, папка **/ (root)** → **Save**.
7. Подождите 1–2 минуты и обновите страницу: вверху появится ссылка `https://ваш-логин.github.io/ne-parsya/`.

**Как обновить:** откройте нужный файл в репозитории → значок карандаша → внесите правку → **Commit changes**. Или снова **Add file → Upload files** и загрузите изменённые файлы поверх старых. Через минуту сайт обновится.

### После публикации: красивое превью в мессенджерах

Telegram, WhatsApp и VK показывают картинку-превью только если адрес картинки полный. Когда у вас появится ссылка на сайт, откройте `index.html` и замените две строки:

```html
<meta property="og:image" content="assets/og-image.png">
<meta name="twitter:image" content="assets/og-image.png">
```

на полный адрес, например:

```html
<meta property="og:image" content="https://ne-parsya.netlify.app/assets/og-image.png">
<meta name="twitter:image" content="https://ne-parsya.netlify.app/assets/og-image.png">
```

Telegram кэширует превью. Если вы уже отправляли ссылку раньше, напишите боту **@WebpageBot** свою ссылку: он обновит карточку.

## Как поменять содержимое

Почти всё меняется в одном файле, **`config.js`**. Его можно открыть любым текстовым редактором: «Блокнотом», TextEdit или VS Code. Следите, чтобы кавычки `'…'` и запятые между блоками остались на месте.

### Username в Telegram

```js
telegramUsername: 'niggadyi',
```

Впишите свой username без `@` и без `https://t.me/`. Он сразу поменяется везде: в кнопках, в плавающей кнопке, в футере и в отправке заявки.

Там же есть `defaultMessage`: этот текст подставляется, когда человек пишет вам, не заполнив конструктор.

### Отзывы и счётчики: подключение базы (один раз, ~5 минут)

Счётчики и отзывы работают сами: посетителей считает сайт, отзывы оставляют клиенты. Хранятся они в бесплатной базе **Supabase**. Пока база не подключена, блок с цифрами и блок отзывов на сайте скрыты.

1. Зарегистрируйтесь на **https://supabase.com** (вход через GitHub или почту) и нажмите **New project**.
   Название: любое, например `ne-parsya`. Пароль базы придумайте и сохраните, регион выберите ближайший (например, Frankfurt). Тариф **Free**.
2. Подождите 1–2 минуты, пока проект создастся.
3. Слева откройте **SQL Editor → New query**. Скопируйте туда **всё** содержимое файла `supabase-setup.sql` и нажмите **Run**. Должно появиться «Success».
4. Откройте **Project Settings → API Keys** (или кнопку **Connect** вверху) и скопируйте:
   - **Project URL** вида `https://abcdefghijk.supabase.co`;
   - **Publishable key** (`sb_publishable_…`). Если в проекте есть только старые ключи, возьмите **anon public**.
5. Вставьте их в `config.js`:

```js
supabase: {
  url: 'https://abcdefghijk.supabase.co',
  key: 'sb_publishable_...'
},
```

6. Задеплойте сайт заново (см. выше) и откройте его: блок с цифрами и кнопка «Оставить отзыв» появятся.

> ⚠️ Вставляйте только **publishable / anon** ключ: он публичный, и база защищена правилами из SQL-скрипта. **Secret / service_role** ключ в сайт не вставляйте никогда.

**Как считаются цифры:**
- **«человек посетили сайт»**: сколько разных браузеров открыли сайт. Повторные заходы с того же браузера не считаются, а один человек с телефона и с ноутбука засчитается дважды.
- **«довольных клиентов»**: сколько опубликованных отзывов с оценкой 4 или 5 звёзд.

Подписи под цифрами меняются в `config.js` → `stats` → `label`. Учтите, что посетитель сайта — это ещё не клиент, поэтому подпись должна честно описывать, что считается.

**Отзывы.** Посетитель нажимает «Оставить отзыв», ставит звёзды, пишет имя и текст, и отзыв сразу появляется на сайте. С одного браузера можно оставить не больше одного отзыва за 12 часов, а простых спам-ботов отсекает скрытое поле-ловушка.

**Удалить отзыв** (спам, грубость): Supabase → **Table Editor → reviews** → отметьте строку → **Delete**.

**Проверять отзывы перед публикацией:** выполните SQL-блок «Модерация» в конце `supabase-setup.sql` и поставьте в `config.js` `reviewsModeration: true`. Новые отзывы будут скрыты, пока вы не поставите `approved = true` в **Table Editor → reviews**. Подписи на сайте поменяются сами.

**Посмотреть число посетителей:** Table Editor → `site_stats`, колонка `visits`. Её можно и поправить вручную.

Бесплатный проект Supabase ставится на паузу, если к базе неделю никто не обращается. Пока на сайт кто-то заходит, этого не случится. Если всё же уснул, зайдите в Supabase и нажмите **Restore project**.

### Кабинет клиента и админ-панель на сайте

Всё, что есть в боте (заказы, суммы, оплаты, чеки, статусы, готовые файлы), дублируется на сайт. Сайт, кабинет и панель лежат на Netlify и в Supabase, поэтому **работают и при выключенном компьютере**.

| Кто | Где | Что видит и может |
|---|---|---|
| Клиент | `cabinet.html` (кнопка «🌐 Кабинет на сайте» в «📦 Мои заказы» и «Мой кабинет» на сайте) | свои заказы, статус, цену, оплачено/осталось, срок, реквизиты, скачивание готовых файлов. Без регистрации: вход по личной ссылке из бота |
| Админ | `admin.html` (команда `/panel` в боте или «Для админов» внизу сайта) | отчёт: выручка по месяцам, заказы по типам и админам, оплаты; все заказы с поиском; назначить цену и срок, сменить статус, написать клиенту, **загрузить готовые файлы**, открыть чеки и файлы клиента |

**Настройка:** по шагам в файле **ИНСТРУКЦИЯ.md** рядом с папкой сайта (шаги 2, 7 и 8). Коротко:

1. Выполните весь `supabase-setup.sql` в Supabase → SQL Editor. Повторный запуск безопасен.
2. В `config.js` → `supabase` впишите **Project URL** и **Publishable key** (публичный). **Secret** ключ на сайт никогда не вставляйте.
3. Админы: Authentication → Users → Add user (почта и пароль, галочка Auto Confirm User), затем в SQL Editor:
   ```sql
   insert into panel_admins(email) values ('admin1@mail.ru'), ('admin2@mail.ru');
   ```
4. Перетащите папку сайта на https://app.netlify.com/drop (войдя в аккаунт) и отправьте боту `/setsite https://ваш-сайт.netlify.app`.

Бот тоже живёт в Supabase (функция `bot`), поэтому действия из панели — цена, статус, сообщение, готовая работа — уходят клиенту в Telegram сразу, даже когда компьютер выключен.

**Мелочи.**
- Файлы из панели — до 20 МБ (ограничение Telegram). Готовые работы лежат по случайным ссылкам, их не угадать. Чеки и файлы клиентов закрыты и открываются только админам по временной ссылке.
- Личная ссылка кабинета работает как ключ: кто её знает, видит заказы этого клиента. Не пересылайте её.

### Примеры работ

1. Положите картинки-превью (скриншот титульника, слайда, чертежа) в папку `assets/works/`. Её нужно создать. Лучше всего подходят файлы JPG или WebP размером около 1200×900 пикселей.
2. Заполните карточку в `portfolio`:

```js
{
  type: 'Курсовая работа',
  subject: 'Экономика предприятия',
  description: 'Анализ финансового состояния, 35 стр., ГОСТ',
  image: 'assets/works/kursovaya.jpg'
},
```

- Строку `placeholder: true` у настоящих работ **удалите**, иначе останется плашка «Пример — замените своими».
- Если `image` пустой, вместо картинки будет серый плейсхолдер.
- Пустой массив `portfolio: [],` скрывает весь блок.

Помните о конфиденциальности: замажьте ФИО, названия ВУЗов и прочие личные данные на скриншотах.

### Вопросы FAQ

В `faq` у каждого пункта есть вопрос `q` и ответ `a`. Новый абзац внутри ответа ставится через `\n\n`.

### Остальные тексты

- **Заголовки, hero-блок, шаги «Как это работает», гарантии** правятся прямо в `index.html`. Найдите нужную фразу поиском (Ctrl+F) и замените.
- **Список услуг** (название, описание, иконка) и **типы работ в конструкторе** заданы массивом `WORK_TYPES` в начале `script.js`.
- **Цвета тем** — переменные в начале `styles.css`: блок `:root` для дневной темы и `:root[data-theme='dark']` для ночной.

## Как работает отправка заявки

1. Клиент нажимает «Отправить заказ в Telegram» и видит окно с превью сообщения.
2. По кнопке «Отправить в Telegram» открывается `https://t.me/<username>?text=<заявка>`, а текст заявки одновременно копируется в буфер обмена.
3. Подстановка текста работает не во всех версиях Telegram, поэтому клиент видит подсказку: «Заявка скопирована — если текст не подставился, просто вставь его в чат».
4. Если заявка очень длинная (например, огромный комментарий), в ссылку попадает сокращённая версия, а полный текст остаётся в буфере. Лимит задаётся параметром `maxUrlLength` в `config.js`, менять его не нужно.

У каждой заявки есть номер вида `#A7K2`, так в переписке проще ссылаться на заказ.

Черновик формы сохраняется в браузере клиента: можно закрыть вкладку и вернуться позже. Кнопка «Очистить форму» стирает черновик.

## Подключение Telegram-бота

Бот «Не Парься» работает в Supabase (см. ИНСТРУКЦИЯ.md). Чтобы сайт, открытый в обычном браузере, вёл в бота, впишите его username в `config.js` (внутри Telegram бот подставляет его сам):

```js
botUsername: 'ne_parsyaa_bot',
```

После повторного деплоя заказы с сайта уходят в бота. Бот сам примет заказ, назовёт цену, проведёт оплату и будет вести переписку.

- Внутри Telegram сайт открывается как Mini App и передаёт заказ боту напрямую.
- Из обычного браузера сайт ведёт в бота по ссылке.
- Если подключена база Supabase, заявка передаётся целиком по коду, и клиенту ничего не нужно вставлять. Иначе текст заявки копируется в буфер, и бот попросит вставить его.


Без `botUsername` сайт работает как раньше: заявка уходит в личку `telegramUsername`.

## Звуки и темы

- Звуки синтезируются в браузере, файлов нет. Клиент может выключить их или поменять громкость кнопкой с динамиком в шапке. Выбор запоминается.
- Сначала тема берётся из настроек устройства (светлая или тёмная). Переключатель в шапке меняет её, и выбор тоже запоминается.
- Если на устройстве включено «уменьшение движения», анимации отключаются.
